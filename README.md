# Салки на выживание — онлайн-сервер

Сервер раздаёт игру (папка `public/`) и ведёт одну общую комнату на 4 места: матч идёт на сервере,
браузеры показывают его и отправляют нажатия. Свободные места занимают боты.

Запуск: `node server.js` (Node 20+, зависимостей нет). Порт берётся из переменной `PORT` (по умолчанию 3000).

Render: Web Service → Region Frankfurt → Build Command `npm install` → Start Command `node server.js` → Free.
